# Architecture decision records

One file per significant decision, numbered in order: `NNNN-short-title.md`.

1. Copy `0000-template.md` to the next free number.
2. Fill it in with status **Proposed**; change to **Accepted** once decided.
3. Never rewrite an accepted ADR's decision. To change it, write a new ADR and
   mark the old one **Superseded by** the new one.

The decisions table in the technical design doc records the choices made
before this directory existed; new or reversed decisions go here.
